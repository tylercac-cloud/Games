## Week 1 checklist (~4–6 hours total, spread out)

1. **Name + entity.** Verify name → file Texas LLC ($300 state fee) or start as sole prop/DBA and convert later.
2. **Domains.** Buy the main domain + one separate sending domain (e.g. `getcomal.com`) so cold email never burns the main one. ~$12 each.
3. **Email infrastructure.** Google Workspace on the sending domain. Set up SPF, DKIM, DMARC. Start warmup immediately (2–3 weeks before real volume — the sequence file explains).
4. **Deploy landing.html** (Netlify free) on the main domain. Swap in your name, email, city.
5. **Record the demo.** Open demo.html full-screen, follow demo-script.md, record with Loom (free tier fine). 2–3 takes, don't polish.
6. **Build the lead list.** Follow lead-sourcing.md → 300 verified contacts in a spreadsheet.

## Week 2+ — the daily 25-minute loop

1. Open a chat with me, say "go." I check what's queued.
2. Sending tool fires 20–30 emails/day automatically (you set it once).
3. You forward me any replies → I draft responses → you approve and send.
4. When someone buys: I build their automation with you, you deliver it.

## Honest math

- 300 emails/mo → expect ~2–5% reply rate cold → 6–15 conversations → 1–3 closes in the first 60 days if the offer lands.
- 3 Front Office clients + care plans ≈ $5K in fees + ~$900/mo recurring. That's the first "steady income" milestone.
- If 600 sends produce zero closes, we don't push harder — we come back and fix the offer together. That's the deal.
